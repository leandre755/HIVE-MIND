# Contributing to HIVE-MIND

Thank you for your interest in contributing to HIVE-MIND! We welcome contributions from developers of all skill levels.

## How to Contribute

1. **Fork the Repository**: Create a personal fork of the repository on GitHub.
2. **Clone your Fork**: Clone your fork to your local machine.
3. **Create a Feature Branch**: `git checkout -b feature/your-feature-name`
4. **Follow Coding Standards**:
   - Write clean TypeScript code with explicit types.
   - Run static analysis: `npx tsc --noEmit`
   - Run tests before submitting: `npm test`
5. **Commit Changes**: Use clear, conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`).
6. **Submit a Pull Request**: Push your branch to GitHub and create a Pull Request targeting the `main` branch.

## Code Standards & Integrity

- Zero-slop policy: Maintain clean architecture, no unused variables or suppressed linter rules.
- Test coverage: Ensure new features include unit or integration tests.
