# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within HIVE-MIND, please report it privately to `ntamonchristleandre@gmail.com`.

Please do not disclose security vulnerabilities publicly until they have been addressed and patched.

All security reports will be promptly investigated, and critical security patches will be released as soon as possible.
